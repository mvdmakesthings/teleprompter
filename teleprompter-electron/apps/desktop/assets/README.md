# Application Icons

Place platform-specific icons here:

- `icon.icns` - macOS icon (512x512 or higher)
- `icon.ico` - Windows icon (256x256 with multiple sizes)
- `icon.png` - Linux icon (512x512 PNG)

You can generate these from a single high-resolution PNG using tools like:
- [electron-icon-builder](https://github.com/safu9/electron-icon-builder)
- [IconSet Creator](https://apps.apple.com/app/iconset-creator/id939343785) (macOS)
- Online converters
